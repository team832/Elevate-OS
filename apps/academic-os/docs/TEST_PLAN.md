# Academic OS — test plan

What is tested where. All tests run on vitest; integration tests use an in-memory PGlite database
built from the live schema (`setupTestDatabase()`, D-025). Fixtures use fictional people only
(`… (fictional)`, `@example.test`), and anything secret-looking is prefixed `test-only-`.

Run: `npx vitest run apps/academic-os` (or `npx vitest run --project academic-os`).

## 1. Unit tests — pure domain (`tests/unit`, no database)

| File | Algorithm (docs/ALGORITHMS.md) | Cases |
|---|---|---|
| `scoring.test.ts` | Exact marks; rule resolution; scoring; finalise validation; aggregation and percentiles | Decimals parsed into integer units and formatted back; values needing > 4 decimals rejected; **120 × −0.25 = exactly −30**; numeric answers canonicalised; section overrides beat the assessment rule; unknown (null) values reported, never assumed 0; positive "penalty" / non-positive reward rejected; negative marking and unattempted marks (**1.75** from 2 right, 1 wrong, 1 blank); all-wrong goes negative; marks for unattempted when configured; cap applied to score and maximum; dropped key questions; numeric short answers; validation of a clean set; **every** issue reported at once (rule incomplete, missing responses, out-of-range, key-version mismatch, duplicate attempts, not enrolled, missing attempt); key length / invalid key answers; ranks with ties (1, 2, 2, 4); absent excluded; percentile ranks; no percentile for a cohort of one; half-up rounding to 4 dp |
| `timetable.test.ts` | Timetable conflict detection | **Touching intervals are not overlaps**; clean timetable is `feasible` (never "optimal"); teacher, batch and room overlaps reported separately; cancelled/rescheduled ignored; holidays (centre-wide and batch-specific) but not exam blackouts; duration mismatch hard for locked length, preference for provisional, unknown length reported; workload cap is a preference by default, hard only when configured, nothing at exactly the cap; weekly workload grouped Monday–Sunday; invalid times and sessions past midnight; `onlyInvolving` filter |
| `capacity.test.ts` | Capacity feasibility | **Legacy Class 12 reproduction from `data/legacy/academic/class12-plan.json`: 157 days × 2 + 31 = 345 gross; 345 − 28 = 317 net vs 305, headroom 12, feasible**; monthly gross slots match the workbook; closure on a weekend not deducted; dated closure replaces the allowance it uses up; two closures on one day deduct once; months over capacity flagged; invalid / overlapping / orphan-extra rules rejected |
| `assessment-schedule.test.ts` | Assessment scheduling constraints | **Legacy known conflict reproduced: exactly the 12 tests of C12-CONFLICT-002 conflict (mock phase 16 Oct–10 Nov), VT14-B's discussion falls on the provisional exam date 14 Nov 2027 and is flagged unverified**; no legacy test before its prerequisites; same-day tests without clock times are warnings; class clash only on overlap (touching fine); assessment clash; configurable minimum gap (warning / hard / boundary); test on or before prerequisite completion; verified blackout not flagged unverified; invalid dates |
| `progress.test.ts` | Coverage; attendance summary; missed classes; trend; catch-up prioritisation | Only verified minutes count as completed, unverified separate, superseded ignored, unplanned chapters listed; 0 % completed vs missing completion for an empty plan; undated plans give unknown planned-to-date; attendance rate excludes unrecorded and excused; missing rate (null) when nothing recorded; late-joiner and absent/excused missed classes, unrecorded not missed; least-squares slope over the last N in date order; insufficient data below the minimum; flat threshold; decline; out-of-range values ignored; catch-up scores deterministic with every factor explained; tie-breaks; assessments outside the horizon or in the past ignored |
| `intake-plans.test.ts` | Enrolment intake decision; plan status rules; responses CSV; settings | Confirm (late joiner); confirm without a batch; every rejection code (unknown/paused programme, unknown/foreign course, unknown/foreign/completed batch, minor without guardian, duplicate in batch, batch full); minor with guardian accepted; age at the 18th-birthday boundary; plan transitions; supersession needs same course and batch scope and a current predecessor; CSV grouping, ABSENT, blanks; CSV problems with line numbers; settings fall back to proposed defaults |

## 2. Integration tests — services and routes (`tests/integration`, PGlite)

Every permission-protected route family has 401/403 cases and an allowed case; state changes are checked
for audit rows where the rule matters.

| File | Covers |
|---|---|
| `curriculum.test.ts` | Courses 401/403 (counsellor, teacher writing, director writing)/400/201; plan version created `proposed`; items; approval request (no items → 400; teacher → 403; duplicate pending → 409); **self-approval refused (403), director cannot decide (403), rejection needs a reason (400), another coordinator approves → locked**; locked plan immutable (409 `INVALID_STATE_TRANSITION`); new version with copied items supersedes the locked plan only on approval (predecessor `superseded`, audited); superseding across courses refused; coverage counts only verified minutes; **teacher outside the batch gets 404, the assigned teacher 200**; concept books readable |
| `timetable.test.ts` | Scheduling 401/403/400/201; back-to-back fine; **409 with the conflict list** for teacher/batch overlaps, holiday, duration mismatch; test sessions not bound to the class length; teacher assignments (coordinator-only, subject must belong to the course, duplicate active assignment 409, teachers read their own, staff picker 403 for teachers); read-only check route `feasible`/`infeasible` (no "optimal"); **teachers only see sessions they teach and their assigned batches**; cancel needs a reason, keeps the row, notifies the teacher, second cancel 409; reschedule into a conflict changes nothing (409), otherwise original `rescheduled` + linked replacement; feasibility `not_assessed` without a plan, then `infeasible` against a locked plan, marketing 403 |
| `teaching.test.ts` | **Teacher logs only own sessions (other teacher's session → 404), auditor 403, future session 400**, duplicate chapter 409, combined lesson; teachers read only their records; only the coordinator verifies, verification fixed once set; **correction preserves the original unchanged as `superseded`, new verified record references it, audited with before/after**; attendance roster by enrolment start date; teacher records own session only; roster/duplicate checks; correction audited |
| `assessments.test.ts` | Create with a configurable rule (−0.25; > 4 decimals rejected); validation lists issues; duplicate rows in an import rejected; CSV import; finalise refused with details until every enrolled student has an attempt; **finalised results 4 / 3 / 0.75 with ranks and percentiles, absent student has no score (not 0)**; finalise twice 409; `academic.assessment.finalised` published without personal data; **re-score with a corrected key creates version 2, keeps version 1 rows unchanged, audits the change**; rule frozen after finalisation; teacher read 200, counsellor 403; scheduling check flags a class clash and the **unverified exam date** |
| `intake-summary.test.ts` | Consumer run route 401/403 (counsellor, teacher, director, auditor); confirmed reply with the documented idempotency key, enrolment `admission_event`; **duplicate publication and duplicate delivery → one student, one enrolment, one reply**; **invalid batch → `academic.enrolment.rejected` (`BATCH_NOT_FOUND`), nothing created**; re-request (attempt 2) confirmed with the same student; duplicate enrolment, batch full, unknown programme, minor without guardian rejected; intake queue; internal summary needs token + allowed caller (401/403/400), returns `AcademicDeliverySummaryV1` with **missing (not zero)** metrics |

| `seed.test.ts` | Seeds idempotent (second run, same row counts); IPMAT baseline 253 / 316.25 h; Class 12 override 305 / 381.25 h (178/70/39/18) locked counts, provisional dates, superseding 313; concept books 133 numbered chapters with planned counts only; CA 9000 min and online 118 h provisional; nothing seeded as delivered; only fictional students; seeded calendar reproduces 345 − 28 = 317 vs 305, headroom 12 |
| `routes.test.ts` | Health, standalone login cookie, seed list exported |

## 3. Not covered by automated tests
- Screens (server components and the client form) are verified by `next build` and typecheck only;
  Playwright E2E is deferred (D-007).
- The wave-3 cross-module flow (Ops publishes → Academic consumes → Ops consumes the reply) is
  simulated here by publishing the Ops event in the test; the Ops consumer is Business Ops' work.
- PostgreSQL 18 (dev) vs PGlite 17 (tests) differences (D-025).
