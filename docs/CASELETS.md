**Read this first.** Permission cells and Tables written are generated, not typed. A row is what the code allows today, not an owner approval: every grant marked Proposed stays Proposed. Every route also refuses signed-out (401) and missing permission (403), and every page signed-out 307 and wrong workspace redirect (roles.json), so rows list only the specific refusals. Tables written come from a static call-graph walk: a table written through a dynamic helper could be missed, so CHECK treats the column as the minimum set.

**Legend.** Actors: dir director, opsm operations_manager, couns admissions_counsellor, fin finance_officer, hr hr_manager, acoord academic_coordinator, teach teacher, mmgr marketing_manager, memp marketing_contributor, padm platform_admin, aud auditor; "(own)" = own-scope grant. API paths are under `<zone>/api/v1/`: no prefix = /ops, `aca/` = /academic, `mkt/` = /marketing, `plat/` = platform; `int/` = `api/internal/v1/`. Origins: ops :3000, academic :3001, marketing :3002, platform :3003. Test: `ops/int/x` = apps/business-ops-os/tests/integration/x, `unit` likewise, `aca`, `mkt`, `plat`, `pkg/<name>/` = packages/<name>/tests/. Tests are the files that import the route or its service; a file listed proves the route is exercised, not every refusal in the row. Flag: `no test`, `no screen`, `owner question` (policy is Proposed or open; do not decide it), or blank.

**Run order.** The structure agent's report to the coordinator names the rows CHECK runs first.
