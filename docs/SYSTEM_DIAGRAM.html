Elevate OS system map

Four Next.js apps on one sign-in and one PostgreSQL database, served from the owner's computer to every device on the office Wi-Fi (npm run office). AI drafts come from free services: Groq, then Gemini, then OpenRouter. Nothing is on the internet.

Start it for the office

npm run office:build once after each update, then npm run office. It prints the Wi-Fi addresses staff open. npm run dev is for this computer only.

Who sees what

Roles in the database decide every page and route on the server. Hiding a menu item is never the control. Teachers see only their own batches and students.

Data ownership

Business Operations owns admissions, fees and students. Academic owns classes, attendance and tests. Marketing owns campaigns and lead follow-up on the one lead record.
